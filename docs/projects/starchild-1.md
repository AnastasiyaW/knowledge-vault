## What it is

Starchild-1 is a research causal world model by Odyssey for teams needing interactive world simulation rather than pre-rendered video.

- Synchronized generation: autoregressively generates synchronized audio and video.
- Streaming input: accepts streaming text, speech, and actions.
- Interactive simulation: demonstrates dialogue, environment navigation, and causal sound effects.

Up to 24 fps on modern hardware.

This is a preview without confirmed public self-serve access. The current Odyssey API page announces Odyssey-2 Max, not Starchild-1.
